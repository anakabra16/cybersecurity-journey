# Day 13 — Linux Disk & Storage Security Audit

## Objective

The objective of this project was to perform a basic audit of disk usage and storage configuration on a Kali Linux system.

## Investigation Areas

- Disk space usage
- Mounted filesystems
- Block devices and partitions

## Commands Used

- `df -h`
- `mount | head -20`
- `lsblk`

## Security Relevance

Disk and storage analysis helps security analysts understand available storage, mounted filesystems, and the system's disk and partition layout.

This information can provide useful context during Linux endpoint security investigations.

## Ethical Scope

This investigation was performed locally on a controlled Kali Linux system for cybersecurity education.

No unauthorized systems were accessed or tested.
